-DataHnalder
The datahandler is responsible for methods to be used for data manipulation.

-Employee
This class represents the Entity Employee, The methods from the datahandler are operated on this entity that exists in our database.

Home Form: Thus form Is the lending Form of the appliacation, Where the HR can see all the actions they can perform.

Employeefrm: This is a form to perfom operations like Registering new Employees, and updating existing employees, it alsogives an option to delete
employees, and that is done on a separate form.
